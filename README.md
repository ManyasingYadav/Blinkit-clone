# 🛒 Blinkit Clone

A Blinkit-inspired grocery e-commerce frontend built using React and Vite.

## 🚀 Technologies Used

* React.js
* JavaScript
* Vite
* HTML5
* CSS3
* ESLint

## ✨ Features

* 🏠 Home page
* 🔍 Product search
* 📦 Product listing
* 🗂️ Product categories
* 🛒 Shopping cart
* 👤 User interface
* 📱 Responsive design

## 📂 Project Structure

```text
src/
├── components/
├── assets/
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

## ▶️ How to Run

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```
